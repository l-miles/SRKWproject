To complete my project, I will be focusing on two things: data visualization optimization, and linear regressions. I will be using tools like Matplotlib and Seaborn to make visually appealing graphs, and I will be grouping my data and running linear regressions on those subgroups using other packages like NumPy and PANDAS.
